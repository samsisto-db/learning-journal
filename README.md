# fde-track

Personal upskilling repo. Tracks my journey from Solutions Architect → more FDE-like over ~6 months. Spike: data engineering + AI/ML/GenAI on Databricks.

## How this repo works

- `roadmap.md` — the living plan. Read this first. Updated weekly.
- `MOC.md` — Map of Content. Index of every note and project.
- `notes/` — concept notes, one per concept. Use `_template.md`.
- `projects/` — shipped artifacts. Each project gets its own subfolder with its own README.
- `weekly/` — weekly retros. Use `_template.md`.

## Workflow

- **Daily:** 1+ hours, commit something (even a half-finished note).
- **Weekly (Sunday):** write the retro, update roadmap, prune open items, decide next week's focus.
- **Monthly:** self-assess across the 5 areas, check anti-signals, course-correct if needed.

## Editing in Obsidian

Open this folder as an Obsidian vault. Markdown is markdown — Obsidian handles `[[wikilinks]]` and renders nicely. Git tracks every change underneath.
